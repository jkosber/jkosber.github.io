# Networking & packet analysis

I completed networking coursework in **NETI 109** and **CSIA 210: Network Protocol Analysis**, covering device configuration, addressing, connectivity and network traffic.

The networking assignments included switch and router setup, IPv4 subnetting, IPv6 addressing and troubleshooting. The repository holds Packet Tracer activity files and written submissions.

The protocol analysis repository contains chapter exercises, midterm and final capstone submissions, and a packet capture.
