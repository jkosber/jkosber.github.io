# Retail technology conversions

**Vaco by Highspring / Verizon · IT Support Contractor · July 2026–Present**

I've supported technology conversions at Verizon retail locations, helping get devices connected for go-live and working through issues after stores reopened. The role has included onsite work and remote coordination with field technicians.

## Printers and network connections

I installed and configured printers, assigned static IP addresses and checked that they connected to the store network.

I used Cisco Meraki Dashboard to check client IP addresses and port status. I also confirmed that field technicians were using the correct Meraki firewall ports and helped troubleshoot connectivity problems.

## Installation and follow-up support

I worked remotely with field technicians to complete installations. After conversion, I continued supporting stores with device and connectivity issues as staff returned to using the systems.
